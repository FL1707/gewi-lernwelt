# Gewi-Lernwelt Klasse 5

Lernplattform für Gesellschaftswissenschaften (Klasse 5, Berlin): Was ist Gewi?, die drei Bereiche, Quellen, Himmelsrichtungen, Kontinente, Weltmeere, Entwicklung der Erde und Entwicklung des Menschen – mit Übungen, Lernkarten und Abschlusstests.

**Zur Seite:** https://fl1707.github.io/gewi-lernwelt/

Die Seite ist eine einzige Datei (`index.html`) und funktioniert ohne Anmeldung. Der Lernfortschritt wird nur im Browser des jeweiligen Geräts gespeichert.

Quellcode zum Bearbeiten liegt in `quellcode/` (Inhalte in `content.js`). Neu bauen: d3.min.js (v7) in `quellcode/` legen und `python3 build.py` ausführen.
